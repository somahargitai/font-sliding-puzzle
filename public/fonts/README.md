# Bundled fonts

These fonts are bundled with the app and committed to the repo because they are
freely redistributable. For strict compliance, add each font's full license text
next to it (OFL.txt / LICENSE) — the table below records the license type.

| File | Family | License | Source |
|---|---|---|---|
| FiraSans-Italic.otf | Fira Sans | SIL OFL 1.1 | Mozilla / https://github.com/mozilla/Fira |
| Gabriela-Regular.ttf | Gabriela | SIL OFL 1.1 | Google Fonts |
| RobotoSlab-SemiBold.ttf | Roboto Slab | Apache License 2.0 | Google Fonts |
| BebasNeue-Regular.otf | Bebas Neue | SIL OFL 1.1 / freeware | Dharma Type / Google Fonts |

Licensed/commercial/trial fonts (Gotham, Baskerville MT Pro, Trajan Pro,
Cocogoose trial, etc.) live in the gitignored `fonts-licensed/` folder at the
repo root — they are NOT committed and NOT shipped. Use them locally via the
planner's "saját fájl" font upload only.
